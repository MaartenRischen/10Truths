# Fonts for the film engine (not included)

`runner.js` loads these files from this folder: `Spectral-300.woff2`, `Spectral-300i.woff2`, `Spectral-400.woff2`, `Spectral-400i.woff2`, `JetBrainsMono-400.woff2`, `JetBrainsMono-500.woff2`. Both families are on Google Fonts under the SIL Open Font License 1.1. Download the Latin woff2 files and save them under these names. `fonts.css` lists the Google Fonts URLs they came from.
